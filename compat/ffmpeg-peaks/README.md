# ffmpeg-peaks (deprecated)

`ffmpeg-peaks` has been replaced by [Peakwright](https://github.com/t4nz/ffmpeg-peaks) and is deprecated.

Existing imports and the `ffmpeg-peaks` command continue to work through this compatibility release. New projects should install `@peakwright/node` for the API or `@peakwright/cli` for the `peakwright` command.
