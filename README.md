# ffmpeg-peaks (deprecated)

> [!WARNING]
> This project is deprecated and archived. It has been replaced by [Peakwright](https://github.com/peakwright/peakwright).

The package remains available only as a compatibility wrapper. Existing imports and the `ffmpeg-peaks` command continue to work, but no new development happens in this repository.

New projects should install:

```sh
bun add @peakwright/node
bun add --global @peakwright/cli
```

See the [Peakwright migration guide](https://github.com/peakwright/peakwright/blob/master/docs/migration.md).
