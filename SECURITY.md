# Security policy

## Supported versions

Security fixes are provided for the latest release only.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/t4nz/ffmpeg-peaks/security/advisories/new). Do not open a public issue.

Include affected versions, reproduction steps, and the potential impact. You can expect an initial response within seven days. A fix and disclosure timeline will be coordinated after the report is confirmed.
